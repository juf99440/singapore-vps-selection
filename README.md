## 新加坡 VPS 的三条线路，选错就是白花钱

新加坡到国内的网络路径大致三形态，价格和体验差别很大。

**纯国际线路**。走公网国际出口，没有针对大陆做优化，成本最低。丽萨主机的落地机就是这一类，官方自己写明了“国际线路，非大陆优化”，建议配香港或日本中转使用，中转香港约 30ms、日本约 70ms。JustHost 新加坡也属于这一类，第三方测评的原话是“电信和联通用户走纯国际线路会绕路，移动用户体感最好”。一篇路由追踪记录里，北京电信方向出现了 181ms、256ms、405ms 的逐跳延迟，上海移动约 76ms，北京移动约 118ms。

**三网优化直连**。电信走 163 骨干、联通走 AS4837、移动走 CMI，各自从广州、北京、上海出口直连新加坡。ByteVirt 的 SG-China Optimized 是这一类，第三方整理的本地 Ping 数据是全国三网平均约 96ms，移动 84ms、电信 91ms、联通 115ms。它电信走的是 163 不是 CN2 GIA，晚高峰稳定性会掉。

**CN2 GIA + 小带宽不限流量**。华纳云把电信 CN2 GIA、移动 CMI、联通 AS9929 写进产品页，宣称平均延迟低至 50ms，代价是带宽只有 2–5Mbps 专用。这种形态适合稳定跑网页和后台，跑不了视频和大文件。

三个延迟数字不能横着比：30ms 是香港中转的结果，50ms 是服务商对自家直连线路的宣称，96ms 是第三方的本地 Ping。测试前提不同，谁快谁慢得在同一条件下测。

## 原生 IP、住宅 IP、纯净度，值不值得加钱？

先把定义摆清楚。朝暮数据的帮助文档写：原生 IP 指 IP 的注册运营商所在国家和服务器物理位置一致；住宅 IP 是互联网服务提供商分配给家庭或个人用户的地址，来自真实家庭网络，在某些场景更容易被判定为真实用户。

然后是争议。丽萨主机把“IP 段向 APNIC 新申请、15 年未被使用过、Scamalytics 欺诈值 0”当成核心卖点，用来解释它为什么适合 TikTok 和 Shopee 运营。朝暮数据的官方 FAQ 直接否定了这套指标：“某些网站提供的 IP 欺诈值检测并没有评分依据，IP 地址也没有纯净、干净、新老的说法。实际上 TikTok 等公司有自己的 IP 地址库和检测手段。”

一边是要卖溢价的商家页面，一边是服务商的帮助文档，两边都没有可独立复核的证据。能确认的只有一件事：平台风控最终按平台自己的库判定，第三方检测站的分数不能当通行证。真要做账号运营，拿最小配置去实测比看任何评分都可靠。

JustHost 这边不靠 IP 故事卖钱。第三方测评的记录是：IPv4 属于广播 IP，能解锁新加坡区 TikTok、ChatGPT、Claude、Netflix、Disney+、Reddit；SIN1 机房测下来解锁不了 Gemini；IPv6 是美国原生段，解锁表现差，别指望用它。它卖的是机房位置、带宽和不限流量，IP 属性只是附带结果。
